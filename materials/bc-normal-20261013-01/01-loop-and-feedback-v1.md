# 从动作拟合到闭环恢复

这段学习把离线拟合、闭环恢复和工程诊断接成一份分析建议。纸面和计算器就能完成。先看一个可以逐步核对的模型，再把它保留的关系带回机械臂；后面的病例仍要由你判断。

## 被执行的是整条链

| 对象 | 本文含义 | 机械臂中的对应例子 |
|---|---|---|
| x_t | 时刻t的完整系统状态 | 机器人/物体状态，必要时包含低层控制器、记忆和延迟状态 |
| o_t=h(x_t) | 策略得到的观测 | 相机图像、关节读数及其预处理；通常不等于全部x_t |
| a_t=π(o_t) | 策略的输出 | 标准化动作向量或其他约定输出 |
| u_t=G(a_t) | 接口解释后实际送入系统的控制量 | 指定位移/速度/目标位置/力矩，须有单位、坐标和时序约定 |
| x_(t+1)=f(x_t,u_t,w_t) | 动力学得到下一状态 | 动作与接触、惯性、噪声等共同决定下一状态 |

这是一条有返回的链：x_t → o_t → a_t → u_t → x_(t+1) → o_(t+1) → a_(t+1)。策略的动作改变了自己下一次要读的输入。若策略有历史/记忆，把π的输入补上历史；有时延或控制器内部状态，也要纳入相应对象，不能因为图写得简短就忽略它们。

BC通常在专家记录D_E上最小化动作代理损失 L_E=E_D_E[ℓ(π(o),a*)]。同源留出动作测试仍在专家产生的观测上比较预测与标签。闭环任务成本 J=E_(τ~p_π)[Σ_t c(x_t,u_t)] 则在被执行策略自己产生的轨迹上计算；p_π同时依赖初始化、动力学、接口和策略。两个指标可相关，但输入分布与评价对象都不同。

例如专家平稳地接近物体，示范里几乎没有“夹爪已偏离、该怎样回到正确方向”的输入。策略一次小偏差把自己带到那种状态，下次预测需要的恰是未充分训练的恢复关系。反馈可能放大它，也可能把它修回来。因此不能从小离线动作损失直接推出闭环必然好，也不能从“闭环”二字直接推出必然失败。

把专家的记录动作按时间重放，检查的是这条给定动作序列能否在当前条件下执行；BC闭环还要让策略读取执行后的新观测并重新选动作。两者没有完成同一种检验。只比较策略输出a相同，也没有自动核过物理控制量u的含义和时间。

## 连贯示范：名义MSE相同，恢复反应不同

以下是无量纲教学模型，不是机械臂实验：目标x*=0，环境x_(t+1)=x_t+u_t，无噪声、无延迟、无限幅。策略u_t=−Kx_t+b。名义专家记录全部为x=0、专家u*=0。比较K_A=0.5、K_B=−0.1，二者b=0.02。

在名义点，两策略都输出0.02，MSE均为(0.02−0)²=0.0004。这个数据没有区分它们离开0之后怎样响应。

定义e_t=x_t−x*=x_t。把策略代入环境：e_(t+1)=e_t−Ke_t+b=(1−K)e_t+b。记ρ=1−K，A为ρ=0.5，B为ρ=1.1。这里e是状态误差，b是动作偏差，ρ是环境与反馈合成后的响应；ρ不是动作MSE。

从e_0=0展开。A第一步为0.5×0+0.02=0.02，第二步为0.5×0.02+0.02=0.03；B第一步同为0.02，第二步为1.1×0.02+0.02=0.042。

| 步t | A：e_(t+1)=0.5e_t+0.02 | B：e_(t+1)=1.1e_t+0.02 |
|---:|---:|---:|
| 0 | 0 | 0 |
| 1 | 0.020000 | 0.020000 |
| 2 | 0.030000 | 0.042000 |
| 3 | 0.035000 | 0.066200 |
| 4 | 0.037500 | 0.092820 |
| 5 | 0.038750 | 0.122102 |
| 6 | 0.039375 | 0.1543122 |

每行的数先成为下一行的输入，正好对应“行动→状态→下一观测→下一行动”。两者在第1步看不出区别，第2步以后才因为邻域响应不同而分开。A把旧误差缩小，但每步仍加b，最终趋于b/(1−ρ)=0.04；所以收缩不等于误差归零。B把旧误差放大再加b，离开名义点后越偏越远。

一般展开为e_t=ρ^t e_0+bΣ_(j=0)^(t−1)ρ^j；ρ≠1时为ρ^t e_0+b(1−ρ^t)/(1−ρ)。ρ=1时则是e_0+tb。严格|ρ|<1且偏差有界时，这个模型的误差有界；是否满足任务容差仍要另外比较。无偏差b=0时，严格收缩才使所有有限初始误差趋于0。边界|ρ|=1要单独处理。

减少b会减小名义MSE和偏差项，不会改变K或ρ；即使名义MSE很小，恢复响应仍可能放大。任务只要求某一时刻落在容差内时，有限成功也不等于一般稳定保证。

## 带回机械臂时保留什么

模型保留了动作改变未来输入、名义拟合不约束恢复、反馈可能缓冲或放大三项结构。它删去了多关节耦合、接触切换、噪声、限幅、观测混叠、控制器内部状态和延迟。真实机械臂需要在其实际接口与任务条件下核验这些关系，不能把表里ρ直接当某个网络的稳定性证书。

任务失败和失稳也需分开：一次没有抓住物体可以没有持续误差放大；一个有偏但有界的轨迹可能仍超出插入容差。接触是否不可逆、专家能否恢复和任务余量都会改变小偏差的代价。

原始依据：专家/策略访问分布的区分见[Ross等，2011，§2](https://proceedings.mlr.press/v15/ross11a/ross11a.pdf)。其中T平方ε界有特定有界代价与0–1错误上界条件，不能把连续动作MSE代成ε。标量示范由本次明确模型推导，数值已由教师核算；它没有真实机器人或学习者运行含义。
