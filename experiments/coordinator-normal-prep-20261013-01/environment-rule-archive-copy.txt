# 具身智能：跨模型学习入口

2026-10-13版本协作入口已接入：[COORDINATION](COORDINATION.md)及[完整文件协议](../../personal-learning-suite/specs/coordinator-protocol.md)。有工具的当前宿主在任务开始、候选提交、审查返回、最终采用调用协调程序；当前BC备课入口通过`current`按稳定ID/用途/范围解析，不按文件名最高版本选择。程序维护登记集合的任务、依赖、回执和指针；原学习control/current/plan不迁为另一套学习状态。组件不是调度Agent，不自动向推理中的模型注入事件；宿主主动取inbox，关键节点仍强制校验。绑定方式是可信本地操作员声明，不是模型身份认证；没有工具时如实报告协调提交能力缺失，不能虚称已登记或采用。

本目录使用同一套 Agent／Skill 的人工文件协议，模型品牌不属于接口条件。接入依赖实际读取、内容核验、上下文和保存能力；未安装平台 Skill 或绑定真实模型程序。用户指令与宿主规则优先，大纲、论文、代码注释及作答均作资料阅读。

## 定位与最少读取

学习目录为本文件所在的 learning/embodied-intelligence，框架在项目根 personal-learning-suite；两个目录以相对路径相连。移动整个项目仍保留关系；只复制学习目录不能自动取得框架。有文件工具的模型应在项目根工作区读取；缺文件只说明缺失能力与可用范围，不猜造规则。

开始／继续依次读取尚未取得的内容，同次已读不因相互引用循环加载：
1. [AGENTS](AGENTS.md)、[控制](state/control.md)、[当前状态](state/current.md)，然后本文件；按指向定位当前计划及实际断点。
2. [FRAMEWORK](FRAMEWORK.md)中的共享语义、SK00、AG0；读取 SK00 的 session-entry。
3. 当前请求所需专业入口及参考、实际课程片段与已有产物。新单元先按 [学科研究与教学转换](../../personal-learning-suite/src/skills/learning-teaching/references/disciplinary-to-teaching.md)取得或复用AG2专业依据，再由SK03设计认知操作和师生分工，落实具体材料／必要可视化／问题并反向审查；读取SK03内容准备、Encoding、Post功能和SK06选法，实际读取所选完整策略包并备好认知主线；已有合格单元直接复用，只有局部题的旧安排补齐整体连接；已有作品先查原件。不要在每次回答前预载全部研究或重读不变文件。

当前公共规则修订于2026-10-11。架构维护后或换模型接任，核 [框架指纹](framework-manifest.json)并读取发生变化的入口／专业规则；文件更新不会自动注入旧聊天上下文。单元由理解目标和整体工作划定，跨轮保持；普通反馈后自动接已备下一份内容／工作，不把每次“继续”当重新开课，不等这句才准备后续。认知工作、实际策略引用和结束依据按 [内容准备](../../personal-learning-suite/src/skills/learning-teaching/references/design-whole.md)维护。

其他专业入口的开发 API 段落描述虚构程序，不是人工教学的前置。人工对象是共享契约的可追溯视图，不冒称已校验 JSON、已认证角色或正式程序授权。

## 当前授权与角色

区分资料导入、用户要求开始学习和学习实际发生。旧记录只授权导入时不自动开课；用户现在明确说开始／继续，或发出 [START_PROMPT](START_PROMPT.md)，即可在该请求与既有约定内开展相应教学和保存。更新真实授权范围不能倒写此前已学习、已接触或已通过。维护框架文件不是开始学习，不创建学习事件。

AG0 组织当前会话；目标／关键设计／重要计划按 AG1，学科实质研究和内容／用途按 AG2，反向专业审查与重要评价按 AG3。认知分析可以把具体专业缺口回问AG2，修复后读回受影响内容并进入实际成品；已经充分的部分保留，不强制新增任务。高能力模型可顺序兼任相容职责，注明同模型自查；能力不足时依赖充分准备与有限授权，仅关键缺项升级。普通讲解、提示、等价呈现、常规反馈和缩时不逐轮审批。重要复核先回原始依据；已看旧结论不能假装忘掉或称盲评，换模型也不自动成为独立核验。

角色与 Skill 名称不自动启动子 Agent。跨会话／模型接任前确认旧执行停止当前活动的面向用户教学；不能确认唯一入口时暂停新提示。提示词、文件锁及清单不提供身份认证、并发隔离或旧聊天拦截，默认单入口顺序处理。

整体单元收束／重要跳过时显式读取AG3相关职责和SK04整体规则（稳定已读可复用），常规局部反馈仍可由AG0完成。恢复区分生成时的prepared快照和已回查的真实展示；以当前checkpoint及确认事实继续。维护新增的派生笔记、材料和代码是准备，不是用户已作答／运行或能力通过；优先接原目标的未完成连接，不重开首次学习。

遵循 SK00 和 SK03 的具体准备规则：
- 缺术语、对象说明或初步表征，或用户请求讲解／示范：先给够用框架、定义、例子及对应关系；再留下可完成的学习者工作。必要输入无需等答错才提供。
- 前提可用、任务有界、错误可定位且有可靠后续讲授：可以先尝试或预测；不能把未知定义连续出成测验。
- 已有合格活动／相关作品：直接执行／评价并复用支持；没有需要的新证据就收束。
- 直接问一个概念：给所需讲解，可以结束；不强迫小测或编造表现。不在未授权的其他课程开档案。

开始回复简短说明当前目的、工作、允许资料和投入边界，随后真正交出必要输入、范例或任务。不是只列“准备完成、证据待收集”。框架、图式、范例、代码按内容功能选择，静态够用不用复杂媒体；来源、教师参考和任务必须能支持当前用途。

目标要求、当前展开、本次工作量分别处理。完整证明、机制推演、条件比较、构造、实现和实验解释有真实需要时保留整体要求；本次分段不降低标准。广度扩展服务必要条件、可辨比较和新情境，不把兴趣变为原目标欠账。

## 常规问答

- 认知目标与整体作品决定单元，普通题目完成不自动结束这段学习。按共享design-whole在反馈后接已备下一份内容／工作，真正需要学习者原答、作品、选择或有效停止条件时才等待，不逐题要求“继续”。说继续时复用主线；旧安排只有局部题则补齐近期整体，不重新从基础第一题开始。
- 同一活动中复用已读取且仍有效的目标、题面、参考和规则。检查当前用户指令及必要控制变化；换模型、上下文缺失、版本变化或争议时再重新定位，不每题重读全框架。
- 反馈前先保留原答与必要代码版本。有文件能力时集中完成必要保存及读回；无工具或失败先交待保存原答正文／实际作品定位，再给反馈，两者分开，不等用户手工保存后才给普通帮助，也不虚称持久保存。保持同一事件的初答、帮助和修订顺序。没有改变目标、控制、计划或需求时，不重复改写所有文件或创建完整对象。
- 已有可靠依据的简单问题，答复默认只包含具体反馈、一个必要解释和下一项工作。确认正确的简单事实可更短；复杂证明和明确“不理解”时按实际需要展开。
- 详细总结和重复索引更新集中在阶段结束或收束。延后整理不延后原答、实际帮助及关键停止点的保存；不能虚称后台还会自动整理。必要原件无法保存时报告待保存。
- 需要查新资料、核验争议或运行实验时说明正在检查什么；未完成前不提前宣称正确或通过。不可用提示词承诺秒级速度。

## 提问时预先提供可选等待动作

在预计需要等待的提问末尾附一句：“提交后若还在等待，可……；做完即可停，回复到达后回到这里。”动作只沿当前产物，通常约 30–60 秒即可完成，例如记下答题理由、圈出不确定处或定位涉及的代码。可以选择不做，不增加必交作业或新的通过条件。

等待动作不得提前泄露正在观察的方法选择或关键答案，也不要求学习者在错误前提上继续长推导。需要自主证据时允许先保存自己的理由；反馈后补充的理由保留实际帮助条件，同题补充仍是同一事件。

用户仍不理解或无法自行继续时，允许短休息；回复到达后从原题和最后可信产物恢复，不用额外测验补偿等待。不要不断追加小任务把等待包装成学习，也不让每次确认一行语法都造成一次长往返；可将同一产物中自然关联的预测、操作与解释合并提交，遇到卡点即可提前反馈。

模型/工具响应、等待及实际学习投入分别记录；未知耗时保持未知。连续出现长等待时减少非必要工具和文书操作，必要时说明宿主/推理延迟仍无法由文件规则消除。

# 共用契约 pl-contracts/0.1.0

日期：2026-10-02。范围：B0 建立的共用规范基线。B1 承载接口见 [保存与入口接口](runtime-b1.md)；真实宿主身份绑定与运行保障尚待后续验证。

依据：N00 第四至八、十至十三节；D00 第一、三、五、六、八、九节；D01 第六、七至十一节；D02—D08 的专项接口；D09 第二至九节。编号和文件指纹见 [来源登记](../resources/source-registry.json)。

本文是唯一共用语义及字段维护源。下方 JSON 是本文内的静态字段约束，检查脚本直接读取它，不另维护手写 schema。专业任务单引用本文。未来发布副本必须由此生成并检查版本一致。0.1.0 只冻结已明确的接口；B1 的存储布局、原子发布、身份映射、删除报告和错误返回需另作实现设计。

## 1. 共同表示

对象具有 `type/id/revision/owner/schema_version/basis_refs`。`revision` 是正整数内容修订；`schema_version` 固定为 `pl-contracts/0.1.0`，不代替目标或判据内容修订。稳定 ID 在同一对象修订间不变，跨对象不复用；引用使用 `{id, revision, locator?}`，历史内容引用具体修订，不偷偷跳到最新。

来源、题面、原答和父产物须有定位。`ArtifactRef` 是 `{path, locator, revision, origin}`；`origin` 可为 `learner_original`、`teacher_reference`、`generated_material` 或 `synthetic_fixture`。个人原件的路径由真实学习工作区解析，不能指向本套件；虚构原件只在 fixtures 中。AI 润色稿另存派生位置，不能替换原答。

需要区分未知的事实用 `Fact = {status, value?, reason?}`。状态为 `known/unknown/not_required/not_applicable/not_executed/deleted`；known 必须有 value，其他状态须有原因且不携带猜造 value。空列表只有在确知为空时使用；缺字段、null、没有记录都不能解释为无帮助、无接触、零成本或已通过。`deleted` 仅表示范围失效，不能携带正文、摘要、内容指纹或可重建信息；若删除包含关联索引，不再保留该标记。

`SourceRef` 在 SourceFragment 中为 `{source_id, declared_revision, locator, identity_kind}`。设计来源用 D/R/N 编号；真实课程来源独立登记；虚构来源使用 `FIX-*`，不得进入通用资源的 D/R/N 台账。文件指纹仅检测非个人设计资源变化，不证明可靠。

`basis_refs` 引用实际依赖；无依赖的原始来源或用户授权可为空，说明出处仍在其专有字段。首期从对象引用扫描生成反向关系，`DependencyEdge` 是可生成视图，不另维护权威图数据库。

SourceFragment 的统一运行表示（2026-10-04 来源接口修复）：`read_scope` 用 `text/formula/figure` 三个独立 Fact；`claims` 保留已说明的主张列表，尚未解释时可保持 unknown Fact；`unread_parts` 为 Fact。`verification.content` 分别记录 `status=supported/partial/pending/error`、`checked_revision`、`scope`、`conditions`、`unchecked_scope`；支持声明再有 `reviewer=AG2`、`method=source_comparison/derivation/test/expert_review`、可定位的 `anchor_refs`。这些是来源读取与核验声明，不是 MaterialUse 的当前用途资格，也不提供程序内容真伪保证。

统一来源进入目标检查时，`verification.content.required_modalities` 是 AG2 对**当前已声明核验范围**作出的非空 `text/formula/figure` 列表；该范围需与相关目标用途相容，由专业责任方确认。检查器要求列出的模态确为 known、有非空范围说明或定位，布尔“已读”标记不能代替范围；核验支持本对象修订且有方法、条件和锚点。未提供这个范围、必要模态 unknown 或核验 pending／旧修订，只限制关联要求，不猜测、不补默认模态。未被当前范围要求的模态可继续 unknown；目标检查通过不能让它们变为已读。原件锚点在受控保存／材料阶段还须可定位读取，元数据完整不证明锚点内容正确。

B2a 原单 Fact `read_scope` 和 `verification.value.recorded_status=supported_for_fixture` 仅作为已有虚构目标输入的兼容载体保留，不自动转换成三模态事实。它可继续供有限目标预览；进入材料检查前必须由 AG2 显式补齐实际模态与统一核验表示，必要时提交新来源修订并重核关联引用。材料阶段按 `MaterialUse.context.required_modalities` 独立检查当前用途，不能用来源的旧范围填补新用途必要模态。已有统一来源缺 `required_modalities` 仍可保存真实已知的读取事实或进行材料核验；用作目标可靠依据时保持 partial。此细化不改下方 B0 静态必备字段表或历史夹具。

内嵌 ExposureEvent 的字段为 `kind/sequence/visibility/content/target_operations/substituted_operations/time`。visibility 区分 `planned/requested/displayed/backend_reference/unknown`；实际题目标题和安排解释若泄露方法也记 displayed；宿主未确认显示时 unknown。初答、反馈和修订按 sequence 排列，时间未知仍保留顺序。`contact_history` 保存按操作定位的初学、最近相关练习/反馈、再接触；严格无接触只在目标确实要求时检查。

`ParentTask` 在 ActivitySpec.parent_task 为 known 时，其 value 必备 `parent_activity_ref/parent_artifact/blocker/entry_basis_refs/alternative_explanations/local_sufficiency/return_connection/budget_ref`。parent_artifact 是规范 ArtifactRef，不能只写父任务标题；return_connection 说明怎样回到同一未完成产物。LearningNeed 可引用活动的 parent_task 定位而不复制；SessionCheckpoint 引用同一父产物。修复够用不是整体通过，模块切换也不增加样本或第二条同目标复习债务。

ObjectRef 不允许只有 id 没有 revision；对象引用的 _ref/_refs 字段均须可定位具体修订，字段明确接受 Fact 的未知/不适用情况除外；SourceRef 按来源声明修订与 locator 定位。静态夹具中的原答必须有非空 ArtifactRef，时间线须有初答，帮助/修订不能以空列表隐藏。授权除主体和决定类型外还须覆盖对象与判据范围；空 scope 不是全域权限。

## 3. 状态、授权与采用

Judgment.support：`unknown/supported/observed_not_met/mixed_or_conflicting`。Judgment.eligibility：`usable/pending_review/withdrawn`。二者独立；参考疑误可保留正面历史支持而限制用途。GoalSpec.time_requirements 只有确实要求才产生缺项；否则 not_required。同原答同条件冲突回原答和判据，不投票、平均或最后到达优先。

阶段分开保存：提出 → 接责 → 专业采用 → 计划实质处置/生效。同人可在同条记录完成，不强制会签。`acceptance.status` 为 `proposed/accepted/partially_accepted/declined`；须有范围、责任和触发。`adoption.status` 为 `candidate/adopted/partially_adopted/recheck/rejected`；有采用者、依据、范围、限制和时间状态，candidate 不成为当前依据。`LearningNeed.disposition.status` 为 `pending/scheduled/partially_scheduled/merged/deferred/no_further_investment/closed/returned`；非 pending 要求理由、未覆盖影响和下一触发；scheduled/partially_scheduled 须有有效承诺引用，merged 须有原需求要求映射。退出投入可伴随目标未完成。

| 专业决定 | 最终责任 | AG0 可获授权范围 |
|---|---|---|
| 目标/前置/判据/版本 | AG1 + 用户的正式用途/范围选择 | 读取与澄清，不降低正式标准 |
| 材料正确性/用途/内容更正 | AG2 | 已核验材料的可靠等价安排；实质新内容升级 |
| 关键教学设计/方法配置维护 | AG1 | 措辞、许可帮助、有限局部适配，关键操作改变升级 |
| 常规评分/条件化判断/有限诊断 | AG3 可委派 | 指定判据、活动、结论范围和升级信号 |
| 重要复核/非标准解/冲突/删除影响 | AG3 | 保存原答和限制用途，不能自行改判 |
| 需求去向/跨目标取舍/有效承诺 | AG1 + 用户资源取舍 | 授权内收束、缩时和滚动，不能扩大预算 |
| 暂停/记录控制/教学展示 | 用户控制；当前 AG0 执行入口 | 立即限制，并按实际可控范围报告 |

binding_status 为 `unbound/verified_for_fixture/host_verified`。verified_for_fixture 仅供虚构静态检查，不能用于真实执行。角色名、技能模式、字段签名不认证提交者；真实权限必须来自宿主工具边界和可核查绑定。当前共用文件系统下开发子代理不是已部署 AG0—AG3。

结果采用次序：① 在读取/持久化候选前查删除、暂停、停用；② 查真实身份、职责、授权范围和委派上限；③ 查目标、判据、材料用途、任务、实际帮助/接触、预算和依赖修订的兼容；④ 分离可保留新事实和失效旧决定；⑤ 相应专业方采用/部分采用/重核/拒绝；⑥ 仅改变承诺、依据或可执行范围时同步计划。普通原答追加及授权反馈不等计划批准。

`operation_id` 以一次逻辑提交为单位，重试不新增事件、样本或需求；并非每个对象各造一个新操作。B1 提交请求携带 `expected_state_revision/operation_id/authorization_refs/changes/adoption_refs`，返回 `committed/conflict/rejected/not_saved` 及实际影响；开发态 `entry_actor` 是受控测试配置，真实 actor_binding 未实现，不能当鉴权。

## 5. 暂停、删除、接管与恢复

只有一个当前用户教学入口。后台默认不展示；接管核对父产物、帮助、版本、预算和限制，execution_epoch 增加且旧范围展示权终止。epoch 只是记录；宿主无法拦截旧输出时采用单入口串行，先确认旧执行结束。不能确认唯一入口就停同活动新题目和提示。旧工作可保留的后台核验范围另授权。

删除先限制、再清可控原件/历史/摘要/派生件/临时/候选/运行个人摘录/验证/已管理导出，并停止受影响后台工作与回传。先检查再读取/落盘迟到载荷，禁止已删内容复活。失去依据后 AG3 按剩余合法证据保留、收窄或撤销用途；不自动补测。磁盘清理不代表上下文消失，必要时结束受影响任务，用仅剩合法材料的新上下文；外部历史和备份只能报告不可控范围。普通回滚不得恢复被删内容。

纠错沿内容传播和要求传播两条链，分别完成材料用途、历史判断、实际误导、计划需求恢复。未知依赖保持相关用途受限。不等待完整新版计划才限制。原答足够直接重评；不够时只提会改变决定的必要补证。

恢复先查控制/有效承诺/目标判据/有效判断/材料用途，再查父产物/原答/帮助/断点。本次重新核对投入；没有摘要只用最后可信事实，不全章重测。预算结束、无进展、用户暂停和证据充分分别记录；停止不能记成达成。

## 让学习实际发生

1. 用户开始／继续后，用 SK00 选择未准备、已有活动、已有作品、Post 或直接讲解分支；首先解决当前内容工作，不让用户填内部字段。

3. 第一条教学回复简短说明本次目的、主要内容与最终工作，随即呈现首份实际输入或已备任务。缺必要术语／表征或用户要示范时，按 [Encoding](../skills/learning-teaching/references/encoding.md)给够用讲解、范例或表示，并留下能完成的关系工作。有可用前提可有界尝试接讲授；已有作品先用。后续主要问题已有依据、按需呈现，纯讲解也可收束。
4. 根据真实回应反馈、提供支持、连接整体或结束；含糊或未预期回答按 [Encoding 的动态适配](../skills/learning-teaching/references/encoding.md#动态调整与返回)处理，普通可回退支持由当前入口执行，重要判断再交 SK04。在 [Post](../skills/learning-teaching/references/post-encoding.md)中区分访问、结构、选择和更新；局部够用即返回，整体仍失败先查接口和原判断。

执行design-whole的认知主线与连续推进：单元启动核AG1／AG2已经实际落实策略正文和目标需要的Post工作；收到普通原答后反馈并接已备下一材料／整体任务，不等“继续”或只宣布局部结束。旧安排只有一道题时先补齐单元，保留全部真实原答及帮助；纯解释、只要反馈、暂停和预算实际结束按用户范围处理。

不暗降目标、扩预算、把参考争议判为用户错误或把 AI 完成的关键操作记成用户自主表现。目标要求、当前展开和本次范围分开；需要完整证明／代码／报告时维护连续父产物，局部成功不代替整体。

## 交出结果与处理异常

有真实作答才记录表现；原答先保留，有文件能力时保存读回再反馈，失败按 SK00 交待保存原答再反馈，教师参考与 AI 整理稿另存。交出实际帮助、必要时间条件、父产物位置、停止原因、下一连接和同一必要需求的去向。只是讲解／展示时记实际教学进展，不补造原答。当前充分即可结束，未来条件未具备不靠即时加题填补。

用户问为什么这样学，解释当前工作与目标／支持的关系；检查自主选法时保留判别线索，用户要求完整依据可展示并转教学。换形式时区分呈现偏好和目标本身：合格同用途直接替换，构图／实现正是目标时说明未覆盖部分，不暗降标。跳过检查后只继续不依赖其已通过结论的合格路径。

授权范围外的重要结论、非标准解或评分冲突交 AG3；来源／参考疑误交 AG2；新目标、关键设计或重要资源取舍交 AG1。说清待决定什么、依据缺什么、哪些可靠工作能继续。无人接责保持发起责任和下一触发，不让用户在线等无限委派。

暂停／缩时立即停止新展开，保留必要收束，标准保持；保存失败区分已发生和待保存。内容纠错沿两链回查，材料、历史判断、实际误导和计划分别恢复，原答够用直接重评。删除和迟到结果按 SK00 控制规则处理，不复活失效依据。

接任确认当前版本、原件、实际帮助、未完成连接、资源和限制，旧执行结束该活动面向用户教学；唯一入口不明暂停新提示。结果采用先控制，再授权／范围，再兼容性，再对应专业采用；只有承诺、依据或执行范围变更需计划整合。

# 开始、恢复与收束

这是 SK00 的日常文件路径，遵守 [共享契约](../../../../contracts/shared-contracts.md)的含义。使用所在课程的真实资料；开发夹具、方法研究结果和大纲建议不属于个人学习事实。

## 辨认用途与授权

持续学习读取所在目录的控制、当前状态和计划引用，再加载 AG0 与当前专业 Skill。稳定活动不反复读全库；重要复核、冲突、内容变化或未覆盖方法才回相关原件。一次性讲解直接完成，用户要求纳入课程时才走其持久记录路径。

“开始学习”或已授权的启动提示词表达了开展相应教学的意图；旧“仅导入”状态不是永久禁教。按实际请求更新本次可做范围，保留此前未发生学习的事实。宿主权限仍需真实可用；缺程序授权对象不等于用户没授权人工教学，也不能伪造已绑定的程序授权。

## 从内容到本次入口

先区分请求尺度。**课程／单元启动**先引用或形成课程粗地图及本次连贯安排，按 [多尺度计划](../../learning-planning/references/multi-scale-plan.md)接上近期整体，再用 [内容准备](../../learning-teaching/references/design-whole.md)备好主要材料、示范、实际任务／问题和反馈依据；不能把它退化成临时开始一道小题。**一次性解释**按请求范围直接讲，不硬加测验。**已有安排恢复**沿原主线、实际帮助与断点继续，充分部分复用；只有旧安排缺当前整体连接时补那部分，不重建全课程。

学习单元沿同一理解目标和整体工作跨轮保持，按内容准备的认知工作、实际选法及连续推进要求执行。旧活动只有局部题时复用事实但补齐单元安排；新单元必读SK06所需选法和Post功能，不能以已有旧范例跳过。用户说“继续”是沿主线推进；正常教学不等待这句才展示下一份已备内容。

1. 确定当前内容和用途。新课程只取粗地图及近期片段；系统建议的近期目标按 [目标规则](../../learning-goals/references/goal-design.md)回对用途及必要知识联系，不只检查题目是否满足自定目标。已有有效且适用目标沿用。方向清楚、正式判据未落实时，可以先开展可靠限定探索，正式通过保持未裁定。
2. 按 [学科研究与教学转换](../../learning-teaching/references/disciplinary-to-teaching.md)先由AG2研究或复用当前专业问题、关键选择、机制、条件变化和证据边界，再用 [SK03 内容准备](../../learning-teaching/references/design-whole.md)设计认知操作、教师／学习者分工及本次主线；[SK02](../../learning-materials/SKILL.md)落实主线核心输入、示范、备用帮助、具体问题与教师参考的用途核验。复杂任务备足整体审查依据，普通活动只备必要分支，不要求所有未来内容。认知分析有专业疑点可回AG2；成品就绪后AG3从原用途先定关键判断／变化再审查，不把审查问题逐一变成新增任务。
3. 根据已有事实选入口：相关真实作品先检查；缺必要对象说明或请求示范时先 [Encoding](../../learning-teaching/references/encoding.md)输入；前提够用、错误可定位且后续讲授可靠时可保留短尝试；已有合格活动直接执行。未知基础不自动触发测评。
4. 第一条教学回复简短说明本次目的、主要内容及最终工作，随后展示一段建立对象和关系的讲解、恰当范例／表征或已备任务；后续核心内容已有实际依据，按节奏呈现。图、式、代码按功能选；静态够用不强做动画，没有实际展示的材料不写已呈现。
5. 按 [C0](../../learning-teaching/references/c0.md)根据真实表现反馈、使用支持并调整，再接主线内已备的材料或工作；局部补充后回同一产物。只在需要学习者贡献或真实停止条件成立时等待／收束；纯讲解不为了制造证据安排必修小题。

时间、设备和先验只补影响可行性的缺项。缺确切预算可开展已授权、随时可停且主线已备的有限输入／探索，时间保持未知；不承诺完整证明、实验、付费调用或整门课程。不能以预算未知省去本次主要内容设计。三问、两张卡、固定间隔或统一深度阶梯均不作门槛。

## Post 与选法

先明确当前要恢复、协调关系、自主选用还是条件更新，读 [Post 功能入口](../../learning-teaching/references/post-encoding.md)。提供允许前提后能继续的，保留帮助并继续；前提可用仍不能连接时，保留父任务、卡点、替代解释、局部够用条件和预算，有限 Encoding 后返回。

需要重新选法时读 [SK06](../../learning-strategies/SKILL.md)及候选完整正文；缺编译包可按规定回原卡，不能凭标题执行。整合不固定由检索解锁，模块往返不重置暴露，不新增父任务或第二份复习队列。

## 反馈与必要保存

按课程记录约定保留实际任务版本、原答／作品位置、关键帮助及先后、修订、必要时间与停止点。有文件能力时原答先保存并读回再反馈，AI 整理稿另存派生位置。无工具或保存失败时，先保留当前可得原话／原版本，交出明确标为待保存的原答正文或现有作品定位，再给反馈；原答与反馈分开，缺失的正文不据摘要补造，不等用户手工保存后才继续普通帮助。正式复核仍需取得合法可回查原件；不能把待保存说成持久记录。没有原答可记实际讲解／展示，不能生成表现事件。

代码、证明和报告引用实际定位与版本；整体作品持续维护，AI 与用户贡献可辨，修改前保留复核需要的用户版本。普通反馈不逐题改目标、发计划或造回执。简单反馈说明具体结果、必要依据与下一动作；复杂论证按需要展开。可选等待动作复用已有任务，不提前泄露待检答案，不增加必修负担。

人工保存用单入口顺序写入并读回，不具有 SQLite 事务或跨聊天锁。失败区分实际发生、已保存、待保存，控制／版本变化后重读再决定；无文件能力交出待保存内容和位置，由有能力者确认。

## 继续与跨模型接任

常规继续先读限制和有效安排，再定位目标／判据、有效判断与材料用途、原答／父产物、帮助时间、断点和未决责任。预算变化后重定范围，稳定部分复用；重要跳过、整体结论和评分争议必须回原始依据。

| 上次停止原因 | 这次具体处理 |
|---|---|
| 预算结束或正常分段 | 接可信父产物尚未完成的连接，复用已完成部分，保留整体标准 |
| 突然中断，无摘要 | 从最后确认事件和现存草稿恢复；未记动作未知，仅补影响入口的缺项 |
| 同一帮助无进展或诊断有反证 | 重审任务、接口和解释或换路，不重复原提问与无限下钻 |
| 内容／判据争议 | 相关用途和确定评分仍受限，核验后按依赖分别恢复；无关可靠工作可继续 |
| 当前目标条件已有充分支持 | 结束重复投入，按有效安排进入下一项；只跟进目标内必要未来条件 |

接任短记录表达当前版本、父产物、实际帮助、未完成连接、限制、资源、下一步和停止条件即可。换模型不重置暴露，摘要不增加样本；普通恢复不全章重测。

当前会话可顺序兼任职责；其他执行者按实际授权与宿主能力交接。确认旧执行停止该活动面向用户教学、新执行明确接任后再继续提示；文件锁或代次不等于关闭旧聊天，无法保障时用单入口。收到、接责、专业采用、进入计划是不同事实，兼任无需模拟通信回执。发起责任跟进未接部分，用户不负责催四个 Agent。

## 控制、纠错与收束

- 为什么这样学／看依据：解释本次工作与目标、已有支持的关系。拟检查自主选择时，先说明观察什么能力，保留具体判别线索；用户要求先看完整理由或参考时满足，并将之后被代做的部分转为帮助后的教学，不以保护测评为由拒绝其有权查看的内容。
- 少讲一点／不用图／换文字：形式不是目标时，用同用途合格表示，保留条件与对应关系；若从公式构图、写代码或跨表征转换正是目标，说明该部分暂未覆盖，可提供支持后继续其他合格工作，不暗改判据，也不把一次偏好写成固定学习类型。
- 暂停立即停止新增任务，保存已有产物；继续可解除用户暂停，仍有效专业限制保留。缩时只缩承诺，正式目标不暗改；超出授权的用途、范围取舍或新增投入交用户决定。
- 要答案或示范可以提供，保留帮助前原答并改变后续证据解释；跳过检查可继续合格教学，未取得的能力证据未知。下一活动确实依赖该未裁定结论时，说明限制并提供不据此作重要跳过的受限路径，不能默认该能力已具备，也不惩罚其选择。
- 异议先定位疑点与原答，限制相关确定结论：AG2 核内容，AG1 核判据影响，AG3 重评，AG0 修复实际误导，计划职能处理安排。沿内容链和要求链回查，原答够用直接重评；材料、历史判断、教学影响和计划分别恢复，系统错误不变为用户欠课。
- 查看按请求定位，避免附带教师参考；导出只取指定合法范围及必要条件，仅摘要时说明不足以独立复核。删除先停用，再清理可控原件、摘要、派生与临时副本，按剩余支持保留／收窄／撤销；不从迟到结果、指纹或旧上下文复活，实际控制边界如实报告。受删内容已在上下文时停止该依赖，以剩余合法资料建立后续上下文，不能虚称宿主历史已清除。
- 够用、暂停、预算结束、无有价值新观察或必要依据缺失时收束。交出真实完成、条件化支持、未完成连接、停止原因、恢复点及同一必要需求的实质去向；未安排明确写未安排。无目标要求的保持／迁移不新增债务，计划日期不算学习发生。

# 学科研究、教学转换与反向审查

用于新单元、专业条件变化或现有安排缺少关键关系时。日常充分的讲解、材料和作品直接复用。AG2、AG1／SK03、AG3 是决定责任，可以顺序兼任；实际委派、角色履责和读取 Skill 是不同事实。本流程不新增共享对象、会签或固定题量。

## 先研究，再设计，再落实成品

**AG2：学科实质研究。**从原学习用途、资料与当前有限单元识别专业问题、关键选择、重要机制、条件变化和证据边界。先弄清专业上需要判断什么、为什么成立，再交给教学方选择认知操作。用途涉及合法变化、结构取舍或联动时，可按 [专业变化与约束分析](../../learning-materials/references/domain-checks.md#专业变化与约束分析自由度)研究；已有可靠分析可直接引用，未明关系先研究，不能先定一套题再只核题解。

研究交接应使教学方取得：当前问题和对象；决定结果的关系及中间理由；哪些条件变化会改变判断、哪些仍可保持；可靠解释、代表案例或合法对照的依据；已核范围、未知和来源定位。深度由当前用途决定，分类仅用于发现缺项，不要求每课逐项展开、每种变化新增一道题。教学方需要必要专业前提，不能让学习者以猜测补齐研究缺口。

**AG1 使用 SK03：专业知识的教学转换。**按用途与学科依据选择近期理解要求，把关键关系转换成可学习的解释、案例和任务，再明确具体认知操作和教师／学习者分工。学科论证顺序可以调整为适合学习的顺序，但成立条件、量词和证据范围保留。概念辨认、机制解释、条件判断、选用、推演、构造、组织和检验按所需工作取舍，不统一升成证明、实现或闭卷训练。

在现有教师安排中接清以下关系即可，不另填一套固定表单：

| 从学科研究取得什么 | 教学转换需要决定什么 | 实际材料与工作怎样承接 |
|---|---|---|
| 专业问题、对象与判断用途 | 学习者要能解释或作出什么判断；哪些暂缓 | 够用对象说明、情境和整体终点 |
| 机制、理由和关键连接 | 哪一跳教师示范，哪一跳学习者追踪／重建／解释 | 可跟踪的讲解、推导、案例与核对依据 |
| 关键选择、合法候选和条件变化 | 需要比较、辨别、选用或重新判断什么 | 合法对照、变式或边界；也允许变化后结论不变 |
| 证据范围及竞争解释 | 学习者需要限定哪项主张、选择什么检验 | 实际数据／条件、可接受多解及不足时的可靠分支 |

教师提供必要定义、规则、工具、连贯示范和可靠反馈；明确教师已提供什么，学习者还需完成哪项当前目标要求的判断、连接或产物，不能按研究视角逐项出题。解释可以完整交付而不配题。需要观察自主工作时，标题、图、箭头、代码默认值与支持同样计入输入；若无需使用目标关系仍能完成，调整实际输入或工作，或限定该表现的用途。完整示范后的追踪或有支持重建不能冒称自主发现。

**AG2 与教学方落实具体资料。**认知操作确定后，再落实可以实际呈现的讲解、例子、图／表／公式／代码、具体问题、备用帮助及教师参考。SK02负责来源与内容／用途核验，SK03负责这些成品承担什么认知工作，AG0负责实际呈现及帮助记录。仅有设计说明、材料清单或后台正确答案还不能交付。

可视化选择服务关键关系：使对象、转换、比较、条件或整体接口可见，并能与正文、公式、数据或代码逐项对应。需要图或交互才制作并检查实际成品；文字或静态图够用时直接采用。图不能删掉成立条件或在自主任务里替学习者作出关键选择。具体核验沿 [领域与对象核验](../../learning-materials/references/domain-checks.md)，不因“可视化已完成”推定学会。

主要问题写出可执行题面、必要输入、允许资源及可靠参考；需要连续论证／实现时接在同一整体产物中。备用支持说明何时给、给到哪里、代做什么、回哪个连接。首份教学呈现前，当前主线所需成品已有可用依据；远期未定不妨碍可靠有限范围。

## 认知分析向学科研究反馈

认知初稿不是单向消费学科稿。解释缺中间理由、对照无区分力、关键条件说不清、表示不闭合、题目只能复制示范或多解没有可靠参考时，把**具体位置、专业疑点及对当前教学的影响**返回 AG2。AG2核来源、对象、机制、条件或代表案例，教学方据回修调整操作与分工；学科已充分而问题在呈现／任务时只修相应成品。目标建议遗漏用途内关系则由 AG1回原依据处理。

回修后实际读回受影响的专业内容，并检查它怎样进入解释、案例、问题、参考或支持，再重核相关判断。充分项保留；没有增量就确认充分或限定未核范围，不虚构回问，不让各方循环重写全文。运行中的真实卡点也可触发同一路径，先辨材料／专业缺口与学习者尚未完成的工作，不把系统错误记成学习者不足。

## AG3：从原用途反向专业审查

先依据原学习用途及必要原始专业条件，独立提出当前应该能处理的关键变化或判断，再检查目标、实际成品和作者总结。问题可以是条件改变后哪些结论需重审、什么证据才支持选择、哪个看似正确的模型仍不能支持用途；不用固定变化清单，也不只复查作者已有题目。先定审查问题不要求给学习者逐一增题。

成品审查找具体支撑链：必要专业关系是否正确且可跟踪；实际输入是否足够；学习者的工作是否留下所需判断；教师参考能否核合法多解、条件不足和帮助影响。原用途覆盖、目标内教学功能、剩余学习者工作和实际适配分别判断，不能用“自定题满足自定目标”替代。

缺专业依据回 AG2，目标取舍回 AG1，转换或呈现缺项回 SK03／SK02；修复后只重核受影响位置。已经充分则按当前范围保留，不为审查新增任务、媒体或必修债务。范围外建议和个体适配未知不成为原目标缺项。细则见 [整体作品评审](../../learning-assessment/references/product-review.md)。

这里“独立提出”要求从原用途重新立问题；同一模型可以依原件自查，但不能称独立 Agent 或盲评。实际子 Agent 先取得最少原始用途与条件、保留先定问题，再接成品；已经看过作者结论时如实说明。多模型赞同也不替代内容核验。

## 协作与证据的边界

有实际委派时记录负责范围、所读版本／原件、实际返回、回问／回修及采用位置。中断后保留已完成部分和真实接手者，不补造调用或完成。顺序兼任只记录实质决定，不制造角色回执。普通反馈仍由单一 AG0入口接已备主线，关键变化才重新进入研究／设计／审查。

研究已取得、认知设计已形成、资料已制作、实际已展示、学习者已作答、能力已获支持分别成立。备课就绪、教师数值检查与审查通过不能证明真实学习效果或多 Agent 净收益；未知也不抹掉已完成的可靠准备。

## Gotchas

- “答案正确”仍可能缺专业问题、机制桥梁或用途所需选择；先查缺的是哪项实质依据。
- 回问需要落到可定位修改并进入实际成品；只在认知稿写“需解释”仍未落实。
- 正确且充分的原材料、参考或作品可以直接保留；审查候选变化不是新的必修清单。
